# Лабораторная работа №3
## Основы обработки цифровых изображений

**Группа:** 10А  
**Вариант:** 10

---

## Цель работы

Цель лабораторной работы — изучить методы цифровой обработки изображений и реализовать их вручную без использования готовых высокоуровневых функций компьютерного зрения.

Для варианта 10 необходимо реализовать:

- два метода глобальной пороговой обработки;
- адаптивную пороговую обработку;
- нелинейные фильтры, основанные на порядковых статистиках;
- ручную работу с пиксельными данными;
- оптимизации, предусмотренные дополнительными требованиями для группы 10А;
- обработку больших изображений без блокировки интерфейса;
- визуальное сравнение результатов обработки.

---

## Постановка задачи

Приложение должно позволять загрузить изображение, выбрать метод обработки, настроить его параметры и сравнить исходное изображение с результатом.

В проекте реализованы три основные группы методов:

1. глобальная пороговая обработка;
2. адаптивная пороговая обработка;
3. нелинейные фильтры на основе порядковых статистик.

Все основные алгоритмы реализованы вручную. Готовые библиотечные реализации Otsu, Sauvola, медианного фильтра и других методов обработки не используются.

---

## Реализация проекта

Проект выполнен в виде веб-приложения на HTML, CSS и JavaScript.

После загрузки изображение считывается через `Canvas` и `getImageData()`, после чего обработка выполняется непосредственно над массивами пикселей.

Используются следующие структуры данных:

```text
Uint8ClampedArray — исходные RGBA-данные изображения;
Uint8Array        — изображение в градациях серого;
Float64Array      — интегральные изображения для локальных статистик.
```

Это позволяет избежать медленного попиксельного доступа через высокоуровневые функции.

Алгоритмы не зависят от интерфейса и работают только с пиксельными буферами.

## Глобальная пороговая обработка

### Метод Оцу

Метод Оцу автоматически определяет оптимальный порог разделения изображения на два класса.

Для каждого возможного значения порога вычисляется межклассовая дисперсия:

$$
\sigma_B^2 = w_0 w_1(\mu_0-\mu_1)^2,
$$

где:

- $w_0$, $w_1$ — доли пикселей двух классов;
- $\mu_0$, $\mu_1$ — средние значения яркости классов.

В качестве итогового порога выбирается значение, при котором межклассовая дисперсия максимальна.

### Iterative Intermeans

Второй метод глобальной пороговой обработки использует последовательное уточнение порога.

Пиксели делятся на две группы относительно текущего значения $T$, после чего вычисляются средние яркости $\mu_1$ и $\mu_2$.

Новое значение порога:

$$
T_{new}=\frac{\mu_1+\mu_2}{2}.
$$

Итерации продолжаются до стабилизации порога.

Наличие двух методов позволяет сравнивать качество глобальной бинаризации на различных изображениях.

## Адаптивная пороговая обработка

Для изображений с неравномерным освещением реализован метод Sauvola.

Для каждого пикселя вычисляется собственный локальный порог:

$$
T(x,y)=m(x,y)\left[1+k\left(\frac{s(x,y)}{R}-1\right)\right],
$$

где:

- $m(x,y)$ — средняя яркость в локальном окне;
- $s(x,y)$ — стандартное отклонение;
- $k$ — параметр метода;
- $R$ — нормирующее значение динамического диапазона.

Пользователь может изменять размер локального окна и коэффициент `k`.

---

## Интегральное изображение

Для ускорения адаптивной обработки используется Summed-Area Table.

Сумма произвольного прямоугольного окна вычисляется по четырём значениям интегрального изображения:

$$
S = I(x_2,y_2)-I(x_1-1,y_2)-I(x_2,y_1-1)+I(x_1-1,y_1-1).
$$

В проекте строятся два интегральных изображения:

```text
sumIntegral      — сумма значений яркости;
squareIntegral   — сумма квадратов значений яркости.
```

На их основе вычисляются среднее значение и дисперсия локального окна.

После построения SAT локальная статистика получается за $O(1)$ на пиксель.

## Нелинейные фильтры на основе порядковых статистик

### Median Filter

Центральный пиксель заменяется медианой значений локального окна. Фильтр хорошо удаляет импульсный шум типа «соль и перец».

### Minimum Filter

Выбирается минимальное значение в локальном окне.

### Maximum Filter

Выбирается максимальное значение в локальном окне.

### Percentile Filter

Позволяет выбирать произвольный процентиль значений локального окна.

```text
0%   → Minimum
50%  → Median
100% → Maximum
```

### Adaptive Median Filter

Размер окна изменяется в зависимости от локальной структуры изображения.

Анализируются значения:

$$
z_{min},\quad z_{max},\quad z_{med},\quad z_{xy}.
$$

Если текущее окно не позволяет определить корректную медиану, его размер увеличивается. Это позволяет удалять более сильный импульсный шум при сохранении деталей изображения.

---

## Оптимизация порядковых фильтров

Вместо полной сортировки значений каждого окна используется 256-уровневая гистограмма яркости.

Для текущего окна хранится количество пикселей каждой интенсивности:

```text
histogram[0 ... 255]
```

При перемещении окна:

- значения уходящего столбца удаляются;
- значения нового столбца добавляются;
- нужный процентиль находится по накопленной гистограмме.

Такой подход уменьшает количество лишних операций сортировки.

## Обработка цветных изображений

Порядковые фильтры выполняются отдельно для каналов:

```text
R
G
B
```

После обработки каналы объединяются обратно. Альфа-канал сохраняется без изменения.

Благодаря этому цветные изображения после Median, Min, Max, Percentile и Adaptive Median остаются цветными.

---

## Обработка границ изображения

Реализованы две стратегии обработки координат, выходящих за пределы изображения.

### Clamp

Используется ближайший граничный пиксель.

```text
10 10 | 10 20 30 40 | 40 40
```

### Reflect

Изображение зеркально продолжается относительно границы.

```text
30 20 | 10 20 30 40 | 30 20
```

Режим обработки границ выбирается в интерфейсе.

---

## Многопоточная обработка

Для больших изображений используются Web Workers.

Количество потоков определяется на основании:

```js
navigator.hardwareConcurrency
```

Тяжёлые вычисления выполняются вне главного потока браузера. Изображение разбивается на диапазоны строк, которые обрабатываются параллельно.

Многопоточная обработка применяется для:

- Sauvola;
- порядковых фильтров;
- Adaptive Median.

Это уменьшает блокировку пользовательского интерфейса при обработке больших изображений.

## Вывод

В ходе лабораторной работы были изучены и реализованы методы глобальной, адаптивной и нелинейной обработки цифровых изображений.

На примере глобальной пороговой обработки было показано, что результат бинаризации зависит от распределения яркости и способа определения порога.

Метод Sauvola позволяет учитывать локальные характеристики изображения и поэтому лучше подходит для изображений с неравномерным освещением. Использование интегральных изображений позволяет эффективно вычислять локальные статистики без полного перебора окна для каждого пикселя.

Порядковые фильтры позволяют обрабатывать импульсный шум. Медианный и адаптивный медианный фильтры особенно полезны при удалении выбросов с сохранением границ объектов.

Дополнительно были реализованы алгоритмические оптимизации: прямой доступ к пиксельному буферу, типизированные массивы, скользящие гистограммы, интегральные изображения и многопоточные вычисления через Web Workers.

В результате разработано приложение, реализующее требования варианта 10 и позволяющее наглядно сравнивать особенности работы различных методов цифровой обработки изображений.
