Что именно измеряется

Алгоритм генерации создаёт 500 000 отрезков фиксированным псевдослучайным генератором. Для каждой плотности данные одни и те же при всех глубинах. Время создания данных исключено из запроса; время построения дерева показано отдельно. На каждом окне выполняются поиск кандидатов, битовая AABB-отбраковка и Коэн–Сазерленд (вариант 10). Графики не содержат заранее заданных значений. Порог 60 FPS соответствует бюджету 16,67 мс на кадр, включая обмен с worker и отображение; достижение проверяется на устройстве при включённой анимации.

Теория алгоритмов

Ключевые формулы, сложности и принципы, которые используются в реализации.

Коэн–Сазерленд

Структурное отсечение по 4-битным кодам положения концов относительно окна. Тривиальное принятие — побитовое OR равно 0; отбраковка — побитовое AND не равно 0. В остальных случаях пересекаем нужную границу.

code = LEFT | RIGHT | TOP | BOTTOM
accept: (code₁ | code₂) = 0
reject: (code₁ & code₂) ≠ 0

Сайрус–Бек · часть 2 варианта 10

Параметрическое отсечение прямыми, содержащими стороны выпуклого многоугольника. Ориентация обхода определяется автоматически. Для каждого ребра сужается интервал t.

P(t) = A + t(B − A)
sign · cross(Eᵢ, P(t) − Cᵢ) ≥ −ε · |Eᵢ|
t₀ ≤ t ≤ t₁

Лианг–Барски · дополнительное сравнение

Параметрическое представление. Для четырёх границ вычисляются значения pᵢ и qᵢ; интервал параметров [t₀, t₁] сужается до видимой части.

P(t) = A + t(B − A), 0 ≤ t ≤ 1
pᵢ · t ≤ qᵢ
pᵢ < 0 → t₀ = max(t₀, qᵢ/pᵢ)
pᵢ > 0 → t₁ = min(t₁, qᵢ/pᵢ)

Устойчивость вычислений

Для геометрических условий используется абсолютная погрешность ε = 10⁻⁷. Параллельные линии, пересечения в вершинах, касания и отрезки нулевой длины имеют отдельную обработку.

ε = 0.0000001
equal(a,b) ⇔ |a − b| ≤ ε
boundary-inclusive clipping

Уайлер–Атертон / контурный граф

Сначала находим пересечения рёбер, расщепляем контуры в этих точках, затем по двум сторонам каждого фрагмента проверяем принадлежность пересечению фигур. По ориентированным рёбрам восстанавливаем замкнутые контуры результата. Расширение графом поддерживает самопересечения и вложенные контуры при правиле чётности.

R = Subject ∩ Window
inside(R) = inside(Subject) ∧ inside(Window)
Контуры результата: отдельные циклы графа

Битовый AABB pre-filter

Перед точным отсечением сравниваются минимальные и максимальные координаты отрезка с окном. Если хотя бы один бит (LEFT, RIGHT, TOP, BOTTOM) установлен, сегмент исключается без делений.

max(x₁,x₂) < xmin − ε → LEFT
min(x₁,x₂) > xmax + ε → RIGHT
AABB_mask ≠ 0 → исключить

Quadtree и производительность

Пространство рекурсивно делится на четыре квадранта. Отрезок опускается в дочерний узел, только если его AABB помещается целиком; иначе хранится в предке. Запрос не обходит узлы вне окна. Типичная скорость зависит от распределения; O(log N) не гарантируется в худшем случае.

построение: O(N · D) обычно
поиск: O(посещённых узлов + кандидатов)
D ≤ 10, N ≥ 500 000

Обозначения на холсте

Серым показана исходная геометрия, синим — отсекатель, зелёным — видимая часть. Оси координат и сетка масштабируются без изменения исходных числовых координат. Все математические операции выполняются в исходной системе координат; Canvas служит только для визуализации.
